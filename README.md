# CouponLive

Live-verified coupons and deals for Indian shoppers: https://couponlive.in

## What this repo is
A public demo of the scraper and coupon-validation pipeline behind CouponLive, being rebuilt for the Nebius x NVIDIA Global AI Hackathon 2026.

## Roadmap
- Self-healing scraper agent (repairs itself when a site's layout changes)
- Eval-gated model router on Nebius Token Factory with NVIDIA Nemotron
- Automated coupon validation
